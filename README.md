# Lukii

Creative portfolio for **Lukii** — craft, code, and ops-lab demos with a dark ninja aesthetic.

## Run

```bash
npm install
npm run dev
```

## Stack

- React + Vite + TypeScript
- Framer Motion
- React Router

## Structure

- `/` — landing + Craft / Code / Ops Lab / Contact
- `/ops/:slug` — sample content-ops guides (e.g. Ember Sovereign)
